# Student-Management-System
A menu driven Student Management system developed using java
Features 
1.add,view,search,update and delete students
2.search students by ID or name
3.Calculate grades
4.display class statistics
5.sort students by marks
6.input validation
7.save and load student data using file handling
8.automatic saving when exiting
Technologies
1.java
2.OOP
3.Arraylist
4.File Handling
5.Exception Handling
Used Concepts
1.classes and Objects
2.Constructors
3.Encapsulation
4.Getters and Setters
5.Methods
6.Loops
7.Conditional Statements
8.ArrayList
9.File I/O
10.Exception Handling
How to Run
javac StudentManagementSystem.java
java StudentManagementSystem
Project Purpose
This project was created to practice java programming,Object-Oriented Programming,collections,file handling,exception handling and menu-driven application development.
